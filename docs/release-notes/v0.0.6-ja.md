# CC Switch Agent v0.0.6

公開日：2026年10月15日。

リモートのプロバイダー一覧で消えていた実行ボタンと、使用中の表示を復元しました。

## 修正内容

- Claude Code、Codex、Gemini CLI、Grok Build のリモート一覧で、未使用プロバイダーに三角形の実行ボタンを表示します。誤った削除操作の表示を修正し、切り替え後に「使用中」の状態を更新します。
- 実行、交換、編集、その他の操作はそれぞれ独立しています。交換を選んでも元のプロバイダーは有効になりません。
- リモート切り替えは Agent の状態に従います。本機のプロキシ設定による誤った制限を適用せず、本機の Claude プラグイン設定も上書きしません。

## アップグレード

- v0.0.5 から更新した場合はデスクトップアプリを再起動してください。プロバイダーや CLI 設定を削除する必要はありません。
- データベーススキーマは **v20** のままです。
- Windows / Linux の x86_64・ARM64 パッケージには今回ビルドした Linux SSH Agent を同梱します。
