# CC Switch Agent v0.0.5

发布日期：2026-10-15。

本版新增跨应用、跨主机的供应商交换，完善请求速度统计，并修复远程供应商编辑与并发切换时的路由和配置一致性问题。

## 主要更新

- **供应商交换**：每个供应商行右侧提供交换入口，可选择本机或已配置的远程主机及目标应用，并调整副本名称、地址、密钥、模型和协议。保留源供应商，副本独立保存，创建后不自动启用。
- **请求速度统计**：请求日志展示首字耗时、总耗时、生成速度与端到端速度。底部总 TPK 按全部筛选结果的输出 token 与对应耗时加权计算；导入记录的估算值和缺失计时会明确标识。
- **远程路由隔离**：连接时加载远端当前供应商，远程请求不再回退到本机供应商或本机故障转移队列。尚未就绪或切换中的路由返回明确的 503，避免误用其他环境的凭据。
- **编辑与重连修复**：编辑未启用的供应商不会改变当前选择；修改当前供应商密钥后使用新配置转发。代理重启后保留远端路由，按主机隔离影子记录，避免同 ID 配置相互覆盖。
- **并发一致性**：Agent 使用跨进程锁串行执行数据库提交与实际配置投影，避免多个切换或编辑请求交错。锁等待超时返回可重试的忙错误，未获锁的操作不写入。

## 升级说明

- 本版数据库结构仍为 **v20**。
- Windows 和 Linux 的 x86_64 / ARM64 安装包均内置由本次源码重新构建的 Linux SSH Agent。
- 升级后重新连接远程目标，以建立新版 Agent 会话并加载远端路由。原有 CLI 配置不必手工删除。
- 供应商交换不会改变源供应商或自动切换当前项；目标应用仍需支持对应接口和模型。
- 无效密钥或订阅权限不足造成的 401/403 需要在供应商账号侧处理。
