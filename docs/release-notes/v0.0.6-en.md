# CC Switch Agent v0.0.6

Released October 15, 2026.

This release restores the missing run buttons and current-provider status in remote provider lists.

## Fixes

- Inactive remote providers for Claude Code, Codex, Gemini CLI and Grok Build show the triangular run button again instead of a remove action. The current provider shows “In use”, and its status refreshes after switching.
- Run, exchange, edit and more actions remain independent. Choosing exchange does not activate the source provider.
- Remote switching follows the Agent's state. Local proxy takeover rules no longer block it, and it no longer modifies local Claude plugin settings.

## Upgrade notes

- When upgrading from v0.0.5, restart the desktop app to load the fix. No provider or CLI configuration needs to be deleted.
- The database schema remains **v20**.
- Windows and Linux x86_64 / ARM64 packages include Linux SSH Agents built for this release.
