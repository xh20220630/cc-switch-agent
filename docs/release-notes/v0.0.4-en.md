# CC Switch Agent v0.0.4

Release date: October 13, 2026.

This release syncs upstream CC Switch **4.0.10** (`479964f2`) while preserving the fork's ephemeral SSH Agent, remote provider sync, remote usage queries and independent updater.

## Changes

- Adopt the upstream sidebar, direct / routing / aggregation modes, session reader, provider icon library, usage improvements and Deep Link fixes.
- Keep the runtime target switcher, remote host settings and bidirectional provider sync in the new interface.
- Refresh provider lists, mode state and usage caches correctly while keeping each host's data separate.
- Keep SSH requests on the remote current provider without applying the local aggregation catalog or mode selection.
- Align Agent and desktop databases with **schema v20** and add remote session summaries, earliest usage dates and scan completion status.
- Fix Linux GTK dependencies and release manifest assembly; publish installers and updater signatures for all supported platforms.

## Upgrade

Upgrading from v0.0.3 migrates schema v18 to v20. Supported existing remote databases are backed up before migration. Local and remote provider choices remain independent, and the fork keeps its 0.x version series and repository-specific updater.

Windows and Linux packages are available for x86_64 and ARM64. This fork does not publish macOS builds.
