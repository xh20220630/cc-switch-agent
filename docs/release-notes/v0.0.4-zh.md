# CC Switch Agent v0.0.4

发布日期：2026-10-13。

本版同步上游 CC Switch **4.0.10**（`479964f2`），保留 fork 的 SSH 临时 Agent、远程供应商同步、远程用量查询和独立自动更新。

## 主要更新

- 同步上游新版侧栏、直连 / 路由 / 聚合模式、会话阅读器、供应商图标库，以及用量统计与 Deep Link 改进。
- 在新版界面中保留远程目标切换器、远程主机管理和本机 / 远程双向供应商同步。
- 修复供应商列表、模式状态和用量缓存的刷新接线；切换主机时保持数据隔离。
- 远程 SSH 请求继续按远程 current 选择供应商，不受本机聚合目录和模式指针影响。
- Agent 与桌面数据库结构对齐至 **v20**，新增远程会话用量汇总、最早用量日期和最近扫描完成时间查询。
- 修复 Linux GTK 依赖和发布清单生成流程，完整发布各平台安装包与自动更新签名。

## 升级说明

- 从 v0.0.3 升级时，数据库从 v18 迁移至 v20。已有受支持的远程数据库升级前会创建一致性备份。
- 本机供应商选择与远程代理选择继续独立保存。
- fork 版本号仍使用 0.x，自动更新地址指向本仓库。
- 本 fork 提供 Windows 和 Linux 的 x86_64 / ARM64 安装包；不提供 macOS 构建。

## 下载

- **Windows ARM64**：`CC-Switch-v0.0.4-Windows-arm64.msi` 或 `CC-Switch-v0.0.4-Windows-arm64-Portable.zip`。
- **Linux x86_64**：`CC-Switch-v0.0.4-Linux-x86_64.AppImage`、`.deb` 或 `.rpm`。
- **Linux ARM64**：`CC-Switch-v0.0.4-Linux-arm64.AppImage`、`.deb` 或 `.rpm`。
