# CC Switch Agent v0.0.4

公開日：2026年10月13日。

上流 CC Switch **4.0.10**（`479964f2`）を同期し、一時的な SSH Agent、リモートプロバイダー同期、リモート使用量照会、独立した自動更新を維持します。

## 更新内容

- 上流の新サイドバー、直接接続 / ルーティング / 集約モード、会話リーダー、アイコンライブラリ、使用量表示と Deep Link の改善を導入しました。
- 新 UI に接続先切り替え、リモートホスト管理、双方向プロバイダー同期を統合しました。
- 接続先ごとにデータを分離し、プロバイダー一覧、モード状態、使用量キャッシュを正しく更新します。
- SSH 要求はリモートの current プロバイダーを使用し、ローカル集約カタログやモード選択の影響を受けません。
- Agent とデスクトップ DB を **スキーマ v20** に揃え、会話使用量集計、最古の使用量日付、スキャン完了時刻の照会に対応しました。
- Linux の GTK 依存関係と更新マニフェスト生成を修正し、各対応プラットフォームのインストーラーと更新署名を公開します。

## アップグレード

v0.0.3 からの更新では DB が v18 から v20 に移行します。対応する既存リモート DB は移行前にバックアップされます。ローカルとリモートのプロバイダー選択は独立したままです。fork のバージョンは 0.x 系列を維持し、自動更新はこのリポジトリを参照します。

Windows と Linux の x86_64 / ARM64 パッケージを提供します。この fork では macOS ビルドを公開しません。
