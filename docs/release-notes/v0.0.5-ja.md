# CC Switch Agent v0.0.5

公開日：2026年10月15日。

アプリやホストをまたぐプロバイダー交換、リクエスト速度の統計を追加し、リモート編集と同時切り替え時の接続先や設定の不整合を修正しました。

## 主な変更

- 各プロバイダー行から本機または保存済みリモートホストと対象アプリを選び、名前、接続先、キー、モデル、プロトコルを調整してコピーできます。元のプロバイダーは保持され、コピーは独立して保存されます。自動では有効になりません。
- リクエストログに初回トークン時間、合計時間、生成速度、全体速度を表示します。合計 TPK は絞り込み結果全体の対象出力トークン数と対応する時間で集計します。推定値と計測値なしの表示も区別します。
- 接続時にリモート側の現在のプロバイダーを読み込みます。ローカルの認証情報やフェイルオーバー先には切り替わらず、接続先が未準備のときは 503 を返します。
- 未使用プロバイダーの編集は現在の選択を変更しません。使用中のキー変更を反映し、プロキシ再起動後もリモート接続先を保持します。ホスト別の ID でローカル設定との衝突を防ぎます。
- Agent のプロセス間ロックでデータベース更新と CLI 設定書き込みを直列化します。ロック待機のタイムアウトは部分更新を残さず、再試行可能なエラーを返します。

## アップグレード

- データベーススキーマは **v20** のままです。
- Windows / Linux の x86_64・ARM64 パッケージには今回のソースで再ビルドした Linux SSH Agent を同梱します。
- 更新後はリモートホストへ再接続し、新しい Agent と接続先情報を読み込んでください。CLI 設定を手動削除する必要はありません。
- コピー先のアプリは対象 API とモデルに対応している必要があります。
- 無効なキーや契約権限による 401/403 はプロバイダーのアカウント側で対応してください。
