# CC Switch Agent v0.0.5

Released October 15, 2026.

This release adds provider exchange across apps and hosts, improves request speed statistics, and fixes remote routing and configuration consistency during provider edits and concurrent switches.

## Changes

- Each provider row has an exchange action. Choose a local or saved remote target and app, then adjust the copy's name, endpoint, key, model and protocol. The source remains available; copies are independent and are not activated automatically.
- Request logs show time to first token, total duration, generation speed and end-to-end speed. Total TPK uses eligible output tokens and their associated durations across the full filtered result set. Imported estimates and missing timings are labeled.
- Connections load the remote current provider. Remote requests never fall back to local credentials or the local failover queue; an unavailable route returns an explicit 503 response.
- Editing an inactive provider preserves the current selection. Active credential edits refresh the proxy snapshot, proxy restarts preserve remote routes, and host-scoped shadow IDs prevent collisions with local records.
- Agent operations serialize database commits and live configuration projection with a cross-process lock. Lock contention returns a retryable busy error without a partial write.

## Upgrade notes

- The database schema remains **v20**.
- Windows and Linux x86_64 / ARM64 packages embed Linux SSH Agents rebuilt from this release's source.
- Reconnect remote targets after upgrading to start the updated Agent and initialize their routes. No manual deletion of CLI configuration is required.
- Exchange creates an inactive copy and preserves the source. The destination app must support the selected API and model.
- Invalid credentials and subscription-related 401/403 responses require action in the provider account.
