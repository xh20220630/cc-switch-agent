# CC Switch Agent v0.0.6

发布日期：2026-10-15。

本版修复远程供应商列表的运行按钮缺失问题，恢复正常切换与“使用中”状态显示。

## 修复内容

- **恢复运行按钮**：远程 Claude Code、Codex、Gemini CLI 和 Grok Build 的未启用供应商行重新显示三角形运行按钮，不再误显示为移除按钮。当前供应商显示“使用中”，切换成功后刷新状态。
- **保留交换入口**：运行、交换、编辑和更多操作各自独立，点击交换不会切换当前供应商。
- **隔离本机状态**：远程切换依据 Agent 状态执行，不再被本机代理接管规则误拦截，也不会改写本机 Claude 插件配置。

## 升级说明

- 从 v0.0.5 升级后重启桌面客户端即可加载按钮修复，无需删除供应商或 CLI 配置。
- 本版数据库结构仍为 **v20**。
- Windows 和 Linux 的 x86_64 / ARM64 安装包均包含本次构建的 Linux SSH Agent。

## 下载

- **Windows x86_64**：`CC-Switch-v0.0.6-Windows.msi` 或 `CC-Switch-v0.0.6-Windows-Portable.zip`。
- **Windows ARM64**：`CC-Switch-v0.0.6-Windows-arm64.msi` 或 `CC-Switch-v0.0.6-Windows-arm64-Portable.zip`。
- **Linux x86_64**：`CC-Switch-v0.0.6-Linux-x86_64.AppImage`、`.deb` 或 `.rpm`。
- **Linux ARM64**：`CC-Switch-v0.0.6-Linux-arm64.AppImage`、`.deb` 或 `.rpm`。
